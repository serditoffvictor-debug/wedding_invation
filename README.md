# Свадебный сайт Виктор & Валерия

Готовый первый прототип свадебного приглашения:
- оливковая стилистика;
- приглашение;
- дата и место;
- карта и маршрут;
- программа с возможностью дополнить позже;
- dress code;
- фотогалерея-заглушки для будущих фотографий;
- RSVP-анкета;
- сохранение ответов в SQLite;
- админ-панель;
- выгрузка ответов в Excel (.xlsx).

## Запуск
1. Установите Python 3.10+.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Откройте `http://127.0.0.1:5000`

## Админка
`http://127.0.0.1:5000/admin?key=change-me`

Для реального размещения обязательно задайте переменные окружения:
- `SECRET_KEY` — секрет Flask.
- `ADMIN_KEY` — пароль админки.
- `PORT` — порт (обычно задаётся хостингом).

## Что осталось заменить
- фотографии Виктора и Валерии;
- финальный тайминг дня;
- при необходимости добавить имя сопровождающего;
- при необходимости заменить карту/маршрут на конкретный сервис.
